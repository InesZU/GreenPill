# GreenPill - AI-Powered Natural Health Assistant

GreenPill is an intelligent chatbot application that provides personalized natural health advice and remedies. Built with Flask and powered by OpenAI's GPT, it offers a user-friendly interface for health-related conversations while maintaining chat history and user sessions.

## Features

- 🤖 AI-powered health assistant
- 👤 User authentication and personalized sessions
- 💬 Real-time chat interface
- 📝 Session management and history
- 🔒 Secure data storage
- 🌿 Natural remedies database
- 📱 Responsive design

## Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS (Tailwind CSS), JavaScript
- **Database**: SQLite
- **AI**: OpenAI GPT-3.5
- **Authentication**: Flask-Login
- **ORM**: SQLAlchemy
